# Trash-PC Tycoon 3D

Комедийный мобильный 3D-симулятор: собирай ПК из мусора со свалки и «честных» деталей
с AliExpress, а потом продавай это чудо техники. Стиль — **Pixel 3D / HD-2D**:
3D-модели из кубов и цилиндров, пиксельные текстуры с Nearest-фильтрацией,
грязный гараж, картон, скотч и ржавчина. Неона нет.

Движок: **Godot 4.3 + C# (.NET 8)**, экспорт в Android APK через GitHub Actions.
Локально APK не собирается — только CI (`.github/workflows/build.yml`).

## Статус: Модуль 2 — Кулибин-сборка, перегрев и датчики

Добавлено поверх Модуля 1:

- **Стол сборки и Drag & Drop** (`Scripts/BuildController.cs`): кнопка «На стол» в
  инвентаре, деталь-призрак следует за пальцем, слоты корпуса/материнки/CPU/кулера/
  RAM/GPU/PSU/HDD/SSD на столе в центре гаража, выбор детали тапом, снятие обратно.
- **Молоток**: деталь, которая не влезла (шанс зависит от состояния: фейки и хлам
  влезают хуже), вбивается двумя ударами — деформируется (сплющивается и ширеет),
  вибрирует и потом сильнее греется.
- **Майонез вместо термопасты**: режим в панели «СБОРКА», свайп пальцем прямо по
  3D-процессору на столе, нужно нанести 70%+.
- **Микрофон** (`Scripts/AndroidSensors.cs`): AudioEffectCapture меряет громкость,
  продувка сдувает пыль со всех деталей и охлаждает ПК в тесте; на десктопе —
  честный fallback кнопкой «Дуть (зажми)». Разрешение `RECORD_AUDIO` в пресете.
- **Акселерометр**: тряска телефона — диагностика «что гремит»; вбитые/убитые/фейковые
  детали могут вылететь обратно в инвентарь, во время теста тряска бьёт по температуре.
- **HeatSystem** (`Scripts/HeatSystem.cs`): стресс-тест 30 секунд, термометр и таймер,
  нагрев зависит от пыли, качества деталей, молотка и майонеза; 88°C — дым и вибрация,
  100°C — провал теста, дешёвый HDD гудит вибрацией уже с 55°C.

## Статус: Модуль 1 — Гараж и Свалка

Реализовано:

- Проект Godot 4 (`project.godot`), главная сцена `Scenes/Main.tscn`.
- Изометрическая ортографическая камера (`Scripts/IsoCameraRig.cs`): угол честной
  изометрии, поворот перетаскиванием, масштаб колесом мыши.
- Гараж из примитивов (`Scripts/GarageBuilder.cs`): бетонный пол, две стены, верстак,
  полка, бочка, одна лампочка на потолке (OmniLight без теней на пол-экрана).
- Главное меню и HUD (`Scripts/UI/MainUI.cs`): деньги, счётчик деталей, кнопки
  магазина и инвентаря, строка сообщений.
- Свалка (`Scripts/TrashHeap.cs`): 3D-куча мусора; тап по экрану делает рейкаст из
  камеры, деталь выкапывается и падает в инвентарь, цветмет сразу превращается в деньги.
- Магазин AliExpress: коробка за 150 ₽, «доставка», вскрытие тапом по 3D-коробке на
  верстаке или кнопкой; внутри — случайная фейковая деталь (перекрашенный куб с
  вентилятором-цилиндром, `Scripts/PartVisualFactory.cs`).
- Инвентарь (`GameState` — автозагружаемый синглтон): список деталей, сдача
  барахольщику за деньги.
- Пиксельные текстуры генерируются в коде (`Scripts/PixelTextureFactory.cs`),
  внешних бинарных ассетов для Модуля 1 не нужно.
- `export_presets.cfg` (Android, arm64) и workflow сборки APK с артефактом.

## Управление (Модуль 1)

| Действие | Как |
| --- | --- |
| Копать свалку | Тап по куче мусора или кнопка «КОПАТЬ НА СВАЛКЕ» |
| Повернуть камеру | Тянуть пальцем / мышью по экрану |
| Масштаб | Колесо мыши |
| Купить коробку | Кнопка «Магазин AliExpress» → «Заказать коробку» |
| Вскрыть коробку | Тап по коробке на верстаке или кнопка «Вскрыть коробку» |
| Продать деталь | «Инвентарь» → «Сдать за N ₽» |

## Структура

```
Scenes/Main.tscn          главная сцена (камера, гараж, свалка, коробка, UI)
Scripts/Main.cs           связка сцены: рейкаст тапов, игровая логика Модуля 1
Scripts/GameState.cs      автозагрузка: деньги и инвентарь (сигналы для UI)
Scripts/PcPart.cs         данные одной детали
Scripts/PartCatalog.cs    каталоги свалки и AliExpress, цены
Scripts/PixelTextureFactory.cs  процедурные пиксельные текстуры (Nearest)
Scripts/PartVisualFactory.cs    3D-вид детали из кубов и цилиндров
Scripts/IsoCameraRig.cs   изометрическая ортографическая камера
Scripts/GarageBuilder.cs  гараж, верстак, лампочка
Scripts/TrashHeap.cs      куча мусора и анимация копания
Scripts/DeliveryBox.cs    коробка AliExpress на верстаке
Scripts/UI/MainUI.cs      меню, HUD, инвентарь, магазин
.github/workflows/build.yml  сборка APK в CI
```
