# Pocket Bunker

2D пиксель-арт игра на выживание для Android (Godot 4 + GDScript).
Игрок заперт в бункере (сетка 10×10), копает ресурсы, строит турели и отбивается от зомби.

## Структура проекта

```
assets/
  sprites/          # Пиксель-арт спрайты (сгенерированы через Pillow)
    blocks/         # 16×16: пол, земля, камень, стена бункера
    entities/       # 32×32: игрок, зомби; 64×64: босс, турель
    items/          # 8×8: патроны
    particles/      # 8×8: кровь, искры, пыль
    ui/             # иконка, маска света фонаря
  tileset/          # TileSet с 4 типами блоков
scenes/
  main.tscn         # Главная сцена: TileMap, игрок, зомби, турели, пули, UI
  player.tscn       # Игрок (CharacterBody2D, фонарь, камера)
  zombie.tscn       # Зомби (CharacterBody2D, атака в касание)
  turret.tscn       # Турель (стрельба по зомби)
  bullet.tscn       # Пуля турели
  craft_menu.tscn   # Меню крафта и строительства
  ui/
    hud.tscn        # Мобильный HUD (HP, ресурсы, кнопки, экран смерти)
    lore_note.tscn  # Сюжетная записка с лором
    damage_number.tscn  # Всплывающая цифра урона
scripts/
  main.gd           # Ядро игры: сетка, копание, день/ночь, экономика, сохранения
  player.gd         # Движение, HP, урон
  zombie.gd         # ИИ зомби, ломка стен, урон
  turret.gd         # Поиск цели, стрельба
  bullet.gd         # Полёт пули, урон при попадании
  craft_menu.gd     # Логика меню крафта
  ui/
    hud.gd          # Логика HUD, цифры урона, экран смерти
    lore_note.gd    # Лор-записка
    lore_manager.gd # Менеджер сюжетных записок
tools/
  gen_assets.py     # Генерация спрайтов через Pillow (без скачивания)
.github/
  workflows/
    build.yml       # Godot headless сборка APK для Android
```

## Управление (ПК)

- `WASD` / стрелочки — движение
- ЛКМ — копание блока под курсором
- ПКМ — строительство (после выбора режима в меню)
- `C` — открыть/закрыть меню крафта
- `Esc` — отмена действия

## Управление (Android)

- Виртуальный джойстик / кнопки на экране HUD:
  - `КОПАТЬ` — копать блок перед игроком
  - `СТРЕЛЯТЬ` — режим стрельбы турелями ( автонаведение )
  - `СТРОИТЬ` — выбрать режим строительства

## Игровой процесс

- **День:** kopайте ресурсы (землю, камень), стройте стены и турели.
- **Ночь:** зомби спаунятся по краям карты и ломают стены, чтобы добраться до игрока.
- **Ресурсы:** земля, камень, патроны, монеты, энергия.
- **Крафт:** патроны, аптечка, апгрейд кирки.
- **Сохранение:** JSON в `user://savegame.json`.

## Сборка APK

Сборка происходит через GitHub Actions (Godot headless):
`.github/workflows/build.yml` — Godot 4.2.2 + Android SDK 34.

## Модули

- **Модуль 1 (готово):** ассеты, TileMap 10×10, освещение, игрок, копание, частицы.
- **Модуль 2 (готово):** зомби, турели, день/ночь, строительство, экономика, крафт, сохранения JSON.
- **Модуль 3 (готово):** мобильный UI, экран смерти, цифры урона, лор-записки, полировка.
